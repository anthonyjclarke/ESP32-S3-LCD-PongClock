Before you install

  1. Use desktop Chrome or Edge and a USB data cable. Close serial monitors.
  2. Enter download mode: hold BOOT, press and release RST, then release BOOT.
  3. Click the button for your board and select its USB serial port. Keep the cable connected until installation finishes; this may take several minutes.
  4. Press RST after installation. On first use, join ESP32-S3-PongClock and configure your WiFi in its captive portal (or open 192.168.4.1).
  5. The clock shows its WiFi IP address at startup. Open that address to choose a mode, brightness and timezone.

If a transfer fails, enter download mode again and retry. The PlatformIO instructions provide an alternative.
